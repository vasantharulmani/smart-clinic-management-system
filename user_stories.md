# Smart Clinic Management System - User Stories

### 1. Patient User Stories
* *As a Patient*, I want to register and log into the portal so that my personal health records are kept secure.
* *As a Patient*, I want to search for available doctors by their specialty and time slots so that I can find the right care.
* *As a Patient*, I want to book, view, or cancel appointments so that I can manage my clinic visits easily.

### 2. Doctor User Stories
* *As a Doctor*, I want to log into my portal so that I can securely view my patients' medical histories.
* *As a Doctor*, I want to view my daily appointment schedule so that I can prepare for my consultations.
* *As a Doctor*, I want to log available time slots and write electronic prescriptions during a visit so that patients get their medicine instructions.

### 3. Admin User Stories
* *As an Admin*, I want to add, update, or remove doctor profiles in the system so that the clinic directory stays accurate.
* *As an Admin*, I want to manage system access and view global appointment reports so that clinic operations run smoothly.
